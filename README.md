# 📨 Spam Message Detector

![Python](https://img.shields.io/badge/Python-3.10-blue)
![License](https://img.shields.io/badge/License-MIT-green)

A **smart and lightweight spam detector** built in Python. It classifies messages as **Spam** or **Not Spam** using simple machine learning / NLP techniques. Perfect for learning or integrating into messaging apps!  

---

## 🔍 Features
- Detects spam messages in real-time  
- Lightweight and easy to run  
- Can be trained on custom datasets  
- Simple Python-based implementation
